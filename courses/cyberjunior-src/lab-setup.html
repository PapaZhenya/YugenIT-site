Состав

Единый изолированный стенд для всех практик курса: атакующая машина и мишени «видят» только друг друга, но не домашнюю/рабочую сеть и (для мишеней) не интернет.

Шаги

1. Изолированная сеть (в первую очередь!)

⚠️ Мишени намеренно уязвимы — их нельзя выпускать в интернет.
  1. В VirtualBox создайте Host-Only или Internal Network (напр. lab-net), подсеть 10.10.10.0/24.
  2. Схема адаптеров:
    • Kali: Внутренняя сеть lab-net + NAT (интернет по необходимости).
    • Мишени: только Внутренняя сеть lab-net (без NAT!).
  3. Проверка изоляции: с мишени ping 8.8.8.8 — ответа быть НЕ должно; с Kali ping <IP мишени> — должен идти.

2. Kali Linux

  1. Скачайте готовый образ Kali для VirtualBox с kali.org.
  2. Импортируйте, настройте адаптеры по схеме выше.
  3. Войдите (kali/kali), смените пароль.
  4. Обновите: sudo apt update && sudo apt -y full-upgrade.

3. Metasploitable 2

  1. Скачайте образ Metasploitable 2.
  2. Создайте ВМ (512–1024 МБ), подключите диск.
  3. Единственный адаптер — Внутренняя сеть lab-net.
  4. Войдите (msfadmin/msfadmin), узнайте IP: ip addr.

4. Веб-мишени (Docker)

sudo apt update && sudo apt -y install docker.io
sudo systemctl enable --now docker
sudo docker run -d -p 80:80  --name dvwa  vulnerables/web-dvwa
sudo docker run -d -p 3000:3000 --name juice bkimminich/juice-shop

Проверьте с Kali: http://<IP>/ (DVWA) и http://<IP>:3000/ (Juice Shop).

Docker тянет образы из интернета РАЗОВО. Скачайте с временно включённым NAT, затем верните адаптер во Внутреннюю сеть.

5. Снапшоты

  • После чистой настройки КАЖДОЙ машины — снапшот clean.
  • Перед рискованным занятием — ещё один снапшот.
  • После поломки — откат к clean (ПКМ → Снимки → Восстановить).

Чек-лист готовности

  • VirtualBox + Extension Pack установлены
  • Виртуализация включена, ВМ стартуют быстро
  • Создана внутренняя сеть lab-net
  • Kali: адаптеры lab-net + NAT, система обновлена
  • Metasploitable: только lab-net, IP известен
  • Веб-мишени открываются с Kali
  • С мишени НЕТ интернета (ping 8.8.8.8 не проходит)
  • С Kali проходит ping до всех мишеней
  • На каждой ВМ есть снапшот clean
  • (опц.) SIEM принимает события
