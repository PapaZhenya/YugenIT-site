Модель TCP/IP, IP-адресация, порты и протоколы, а также чтение трафика в Wireshark с сравнением HTTP и HTTPS.

Цели модуля

  • Понимать модель TCP/IP и путь пакета
  • Разбираться в IP-адресации, портах и протоколах
  • Читать трафик в Wireshark и видеть разницу HTTP/HTTPS

Конспект

Почти каждая атака проходит через сеть, поэтому понимание сетевого стека — обязательная база. Данные передаются по уровням; каждый добавляет свой заголовок.

Стек TCP/IP (упрощённо)

  • Канальный — передача внутри локального сегмента (MAC-адреса).
  • Сетевой (IP) — маршрутизация между сетями по IP-адресам.
  • Транспортный (TCP/UDP) — доставка до службы. TCP надёжен и с установкой соединения, UDP быстр и без гарантий.
  • Прикладной — HTTP, DNS, SMTP.

Порты и рукопожатие TCP

IP указывает на хост, порт — на службу. TCP открывается через three-way handshake: SYN → SYN-ACK → ACK.

DNS и HTTP против HTTPS

DNS превращает имя в IP; вокруг него строятся фишинг и отравление кэша. HTTP передаёт данные открытым текстом (включая логины), HTTPS добавляет TLS-шифрование.

Порты наизусть

HTTP 80, HTTPS 443, SSH 22, FTP 21, SMTP 25, DNS 53, RDP 3389.

Лабораторная работа

Часть A. Развёртывание лаборатории

  1. Установите VirtualBox и создайте ВМ Kali Linux.
  2. Настройте два адаптера: NAT (интернет) и Host-Only/Internal (изолированная сеть).
  3. Проверьте связность ping внутри лаб-сети.

Часть B. Захват трафика HTTP

  1. Запустите Wireshark на интерфейсе лаб-сети.
  2. Откройте HTTP-ресурс с формой ввода.
  3. Найдите three-way handshake (SYN, SYN-ACK, ACK).
  4. Отфильтруйте HTTP и найдите данные формы в открытом виде.

Часть C. Сравнение с HTTPS

  1. Повторите захват при открытии HTTPS-ресурса.
  2. Убедитесь, что содержимое зашифровано.
  3. Зафиксируйте вывод: что видно в HTTP и скрыто в HTTPS.

Задания для самостоятельной работы

  • Нарисуйте схему пути пакета с подписью каждого уровня и заголовка.
  • Объясните, почему вход через HTTP в публичном Wi-Fi опасен и что меняет HTTPS.

Связь со спиралью курса. Настроенная лаборатория (Kali + изолированная сеть) станет рабочим местом для всех практик.
