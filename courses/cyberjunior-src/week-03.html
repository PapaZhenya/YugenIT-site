Навигация в Linux из командной строки, модель прав доступа и чтение системных логов Linux и Windows.

Цели модуля

  • Уверенно навигировать в Linux из командной строки
  • Понимать модель прав и принцип наименьших привилегий
  • Находить и читать системные логи Linux и Windows

Конспект

Инструменты ИБ живут в командной строке, а расследование начинается с логов.

Файловая система и права Linux

Дерево от корня /, всё есть файл. Права — три набора (владелец/группа/остальные) в виде rwx. chmod меняет права, chown — владельца, sudo даёт временные привилегии root. Избыточные права (777) — частая причина компрометации.

Логи как источник истины

В Linux — /var/log (auth.log — входы, syslog — система). В Windows — Event Viewer: Security (входы 4624 успешный, 4625 неудачный), System, Application.

Active Directory на пальцах

В корпоративной среде Windows-машины в домене под управлением Active Directory — каталога пользователей, групп и политик. Понимание AD критично для Blue Team, потому что именно его атакуют для захвата всей сети.

Лабораторная работа

Часть A. Навигация и файлы

  1. Освойте: pwd, ls -la, cd, cat, less, head, tail, grep.
  2. Создайте каталог и файлы, потренируйтесь перемещаться и просматривать.

Часть B. Права доступа

  1. Создайте пользователя и файл; меняйте права через chmod.
  2. Проверьте, что может и не может другой пользователь.
  3. Покажите, почему права 777 на файл с секретом опасны.

Часть C. Чтение логов

  1. Найдите в /var/log/auth.log успешные и неудачные входы через grep.
  2. Напишите однострочник, считающий неудачные входы.
  3. В Windows-ВМ найдите события 4624 и 4625 в Event Viewer.

Задания для самостоятельной работы

  • Составьте шпаргалку из 20 команд Linux с описанием.
  • Опишите, как принцип наименьших привилегий снижает ущерб при компрометации.

Связь со спиралью курса. Чтение логов и командная строка напрямую понадобятся в блоке реагирования (недели 9–10).
