  • Практиковать threat hunting по гипотезе

Конспект

Реактивное расследование — половина работы Blue Team. Вторая — проактивный поиск и системное понимание тактики атакующих.

Cyber Kill Chain. Этапы: разведка → доставка → эксплуатация → закрепление → управление (C2) → действия у цели. Прервав любое звено, защитник срывает атаку.

MITRE ATT&CK. База знаний о реальных техниках, сгруппированных по тактикам (зачем) и техникам (как, с ID вроде T1110). Общий язык Blue Team: что искать в логах и где ставить детекты.

Threat hunting. Проактивный поиск угроз, которые не поймали правила. Аналитик выдвигает гипотезу («если атакующий закрепился — будут следы в автозагрузке») и проверяет по данным.

Материал: датасет «Инцидент №2» (phishing/hunt) — CSV событий SIEM. Студент сам проставляет теги ATT&CK, затем сверяется с тэггированной версией. См. datasets/scenario2_phish_hunt/.

Лабораторная работа

Часть A. Сопоставление с kill chain

  1. Разложите Инцидент №1 из недели 9 по этапам Cyber Kill Chain.
  2. Для каждого этапа укажите меру, которая прервала бы цепочку.

Часть B. Картирование по ATT&CK

  1. Откройте датасет Инцидента №2 (siem_events.csv).
  2. Для каждого подозрительного шага определите тактику и технику (ID).
  3. Обратите внимание на «неожиданных родителей» процессов и доступ к lsass.

Часть C. Threat hunting

  1. Сформулируйте 3 гипотезы поиска, которые поймали бы атаку раньше.
  2. Проверьте гипотезы по данным CSV.
  3. Предложите по правилу детекта на три ключевых шага.

Задания для самостоятельной работы

  • Составьте таблицу «тактика → техника → как детектировать» для 5 техник ATT&CK.
  • Объясните на примере разницу между мониторингом и threat hunting.
