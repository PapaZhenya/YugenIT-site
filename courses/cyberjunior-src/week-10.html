Модуль блока «Реагирование» показывает, как использовать Cyber Kill Chain и MITRE ATT&CK для разбора кибератак и вести проактивный threat hunting в работе Blue Team.

Цели модуля

  • Использовать Cyber Kill Chain для анализа атаки
  • Сопоставлять действия с MITRE ATT&CK
  • Практиковать threat hunting по гипотезе

Как это выглядит (схема)

Cyber Kill Chain — прерви любое звено:

Разведка -> Доставка -> Эксплуатация -> Закрепление -> C2 -> Действия у цели
   |           |            |              |           |         |
   прерви ЛЮБОЙ этап -> вся атака сорвана

MITRE ATT&CK — тактики и техники:

Тактика (зачем): Initial Access | Persistence | Exfiltration ...
Техника (как):   T1566 фишинг   | T1547 автозапуск | T1041 выгрузка

Конспект

Реактивное расследование — половина работы Blue Team. Вторая — проактивный поиск и системное понимание тактики атакующих.

Cyber Kill Chain. Этапы: разведка → доставка → эксплуатация → закрепление → управление (C2) → действия у цели. Прервав любое звено, защитник срывает атаку.

MITRE ATT&CK. База знаний о реальных техниках, сгруппированных по тактикам (зачем) и техникам (как, с ID вроде T1110). Общий язык Blue Team: что искать в логах и где ставить детекты.

Threat hunting. Проактивный поиск угроз, которые не поймали правила. Аналитик выдвигает гипотезу («если атакующий закрепился — будут следы в автозагрузке») и проверяет по данным.

Материал: датасет «Инцидент №2» (phishing/hunt) — CSV событий SIEM. Студент сам проставляет теги ATT&CK, затем сверяется с тэггированной версией. См. datasets/scenario2_phish_hunt/.

Глубже в тему

Cyber Kill Chain как инструмент защиты

Модель описывает атаку по этапам: разведка → доставка → эксплуатация → закрепление → управление (C2) → действия у цели. Ценность — в том, что, прервав любое звено, защитник срывает всю атаку. Она помогает понять, где именно была замечена активность и что остановило бы её раньше.

MITRE ATT&CK — общий язык Blue Team

ATT&CK — база реальных техник, сгруппированных по тактикам (зачем) и техникам (как, с ID вроде T1566). Это общий язык: аналитики описывают поведение атакующего одинаково, знают, что искать в логах и где ставить детекты. Умение картировать инцидент по ATT&CK — ключевой навык.

Threat hunting: искать, не дожидаясь алерта

Хантинг — проактивный поиск угроз, которые не поймали правила. Аналитик выдвигает гипотезу («если атакующий закрепился, будут следы в автозагрузке») и проверяет по данным. Это отличает зрелый SOC от реактивного «ждём алерт».

Ещё один пример: подозрительная цепочка процессов

В логах WINWORD.EXE запускает powershell, тот лезет в сеть на неизвестный IP, затем кто-то обращается к lsass. По отдельности — «шум», вместе — классическая цепочка: фишинговый документ → запуск кода → C2 → кража учётных данных. Blue Team ловит именно такие связки, а ATT&CK даёт им имена. Так разрозненные события складываются в понятную историю атаки.

Пошаговый разбор: картируем инцидент по ATT&CK

  1. Возьми события инцидента (датасет scenario2_phish_hunt).
  2. Для каждого шага определи тактику (зачем) и технику (как, ID).
  3. Начни с очевидного: фишинг → T1566, автозапуск → T1547.
  4. Отметь «неожиданных родителей» процессов (WINWORD → powershell) и доступ к lsass.
  5. Собери карту: тактика → техника → доказательство в логах.

Ключевые термины

  • Cyber Kill Chain — этапы атаки (7 шагов).
  • MITRE ATT&CK — база тактик и техник.
  • Тактика / техника — зачем / как (с ID).
  • C2 — канал управления атакующего.
  • Threat hunting — проактивный поиск угроз.
  • Персистенция — закрепление в системе.

Частые ошибки и мифы

  • Миф: мониторинг = хантинг. Мониторинг ждёт алерт; хантинг идёт от гипотезы.
  • Ошибка: смотреть события по отдельности. Сила — в связках (цепочках).
  • Миф: ATT&CK — для «элиты». Это рабочий инструмент даже для junior-аналитика.
  • Ошибка: игнорировать «неожиданных родителей» процессов. Это яркий признак атаки.

Частые вопросы (FAQ)

  • Чем kill chain отличается от ATT&CK? Kill chain — крупные этапы; ATT&CK — подробные техники.
  • Нужно ли учить все техники ATT&CK? Нет, освой логику и частые техники.
  • Что такое C2? Канал, через который атакующий управляет заражённой машиной.
  • Хантинг — это для junior? Базовые гипотезы — да, отличная тренировка мышления.

Шпаргалка модуля

  • Kill Chain: разведка→доставка→эксплуатация→закрепление→C2→действия. Прерви любое звено.
  • ATT&CK: тактика (зачем) + техника (как, Txxxx).
  • Хантинг = гипотеза → проверка по данным.
  • Красные флаги: WINWORD→powershell, доступ к lsass, автозапуск в реестре.
  • Итог — карта ATT&CK + правила детекта.
