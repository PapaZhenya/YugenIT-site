# Инцидент №2 — Фишинг и продвижение по сети (threat hunting)

## Легенда
Сработал слабый сигнал EDR на рабочей станции WKS-02. Явного алерта «взлом» нет — нужно
проверить гипотезу вручную. Вам выгружен CSV с событиями из SIEM за утро.

## Что вам дано
- `siem_events.csv` — события (Sysmon / Windows Event / почтовый шлюз) в хронологическом виде.

## Задача (threat hunting + ATT&CK)
1. Найдите точку входа (initial access). Что её выдаёт?
2. Проследите цепочку: как из открытия документа получилось выполнение кода?
3. Найдите механизм закрепления (persistence).
4. Где произошёл переход на другой хост (lateral movement)? Как именно?
5. Какие данные были украдены и куда отправлены?
6. Сопоставьте КАЖДЫЙ подозрительный шаг с техникой **MITRE ATT&CK** (тактика + ID).
7. Сформулируйте 3 гипотезы для проактивного поиска, которые поймали бы это раньше.
8. Предложите по одному правилу детекта (detection) на 3 ключевых шага.

## Подсказки
- Ищите «неожиданных родителей» процессов: WINWORD.EXE, порождающий powershell/cmd — красный флаг.
- Обращения к неизвестным внешним IP на 443 — возможный C2 или exfil.
- Доступ к lsass.exe — почти всегда credential dumping.
- Открывайте CSV в LibreOffice Calc или грепайте по столбцам.
