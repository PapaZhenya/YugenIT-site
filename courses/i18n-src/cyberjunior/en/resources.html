Tools (free / open-source)

  • Kali Linux — a distribution with a built-in arsenal of tools.
  • Wireshark — network traffic analysis.
  • Nmap — network and service scanning.
  • Burp Suite Community / OWASP ZAP — intercepting and testing web requests.
  • John the Ripper / Hashcat — working with password hashes.
  • Wazuh / ELK Stack — SIEM and monitoring.

Recommended order

  1. Start — OverTheWire Bandit (Linux) and TryHackMe.
  2. Web block (week 5) — PortSwigger Academy is mandatory.
  3. Final (week 12) — picoCTF or a machine from VulnHub/HackTheBox for the audit.
