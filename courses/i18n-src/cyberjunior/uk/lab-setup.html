Кроки

1. Ізольована мережа (у першу чергу!)

⚠️ Мішені навмисно вразливі — їх не можна випускати в інтернет.
  1. У VirtualBox створіть Host-Only або Internal Network (напр. lab-net), підмережа 10.10.10.0/24.
  2. Схема адаптерів:
    • Kali: Внутрішня мережа lab-net + NAT (інтернет за потреби).
    • Мішені: лише Внутрішня мережа lab-net (без NAT!).
  3. Перевірка ізоляції: з мішені ping 8.8.8.8 — відповіді бути НЕ повинно; з Kali ping <IP мішені> — має проходити.

2. Kali Linux

  1. Завантажте готовий образ Kali для VirtualBox з kali.org.
  2. Імпортуйте, налаштуйте адаптери за схемою вище.
  3. Увійдіть (kali/kali), змініть пароль.
  4. Оновіть: sudo apt update && sudo apt -y full-upgrade.

3. Metasploitable 2

  1. Завантажте образ Metasploitable 2.
  2. Створіть ВМ (512–1024 МБ), підключіть диск.
  3. Єдиний адаптер — Внутрішня мережа lab-net.
  4. Увійдіть (msfadmin/msfadmin), дізнайтеся IP: ip addr.

4. Веб-мішені (Docker)

sudo apt update && sudo apt -y install docker.io
sudo systemctl enable --now docker
sudo docker run -d -p 80:80  --name dvwa  vulnerables/web-dvwa
sudo docker run -d -p 3000:3000 --name juice bkimminich/juice-shop

Перевірте з Kali: http://<IP>/ (DVWA) і http://<IP>:3000/ (Juice Shop).

Docker тягне образи з інтернету ОДНОРАЗОВО. Завантажте з тимчасово увімкненим NAT, потім поверніть адаптер у Внутрішню мережу.

5. Знімки стану

  • Після чистого налаштування КОЖНОЇ машини — знімок clean.
  • Перед ризикованим заняттям — ще один знімок.
  • Після поломки — відкат до clean (ПКМ → Знімки → Відновити).

Чек-лист готовності

  • VirtualBox + Extension Pack встановлені
  • Віртуалізація увімкнена, ВМ стартують швидко
  • Створена внутрішня мережа lab-net
  • Kali: адаптери lab-net + NAT, система оновлена
  • Metasploitable: лише lab-net, IP відомий
  • Веб-мішені відкриваються з Kali
  • З мішені НЕМАЄ інтернету (ping 8.8.8.8 не проходить)
  • З Kali проходить ping до всіх мішеней
  • На кожній ВМ є знімок clean
  • (опц.) SIEM приймає події
