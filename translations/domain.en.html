☁️ Cloud Basics

Description:

Cloud Basics covers the fundamentals of cloud technologies and working with cloud infrastructure. Cloud systems let you run servers, store data, and manage services over the internet. Today, cloud technologies are used in virtually every modern IT company.

In simple terms:

It's running servers and services over the internet without needing your own physical hardware.

Microsoft Azure

Description:

Azure is Microsoft's cloud platform for running servers, applications, and various IT services. Azure is used for cloud infrastructure, data storage, virtual machines, and enterprise systems. The platform is widely adopted in enterprise environments and large companies.

In simple terms:

It's Microsoft's cloud for running servers and services over the internet.

Amazon AWS Basics

Description:

AWS (Amazon Web Services) is one of the most popular cloud platforms in the world. AWS provides servers, databases, networks, and a wide range of cloud services for companies and developers. Many modern websites and applications run on AWS.

In simple terms:

It's Amazon's massive cloud system for servers and applications.

Virtual Machines

Description:

Virtual Machines are virtual computers that run inside a physical server. Each virtual machine has its own operating system and settings. Virtualization allows several servers to run on a single device.

In simple terms:

They're virtual computers living inside one real server.

Microsoft 365

Description:

Microsoft 365 is a cloud-based suite of Microsoft services and applications for work and business. It includes Outlook, Teams, OneDrive, Word, Excel, and other tools. Microsoft 365 is widely used by companies for collaboration and user management.

In simple terms:

It's Microsoft's cloud services for work, email, and documents.

Microsoft Entra ID

Description:

Entra ID is the identity and access management system within Microsoft's cloud infrastructure. It was previously called Azure Active Directory. Entra ID is used for authentication, security, and managing employee access to company services.

In simple terms:

It's the sign-in, user, and security system for Microsoft's cloud.

☁️ Cloud Systems

Description:

Cloud Systems are modern cloud infrastructures that run servers, databases, applications, and network services. Cloud systems make it possible to scale projects quickly and manage infrastructure over the internet. They form the foundation of most modern IT services.

In simple terms:

They're servers and services that run in the cloud over the internet.
