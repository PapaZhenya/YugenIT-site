☁️ Cloud Basics

Descripción:

Cloud Basics son los fundamentos de las tecnologías en la nube y del trabajo con infraestructura en la nube. Los sistemas cloud permiten ejecutar servidores, almacenar datos y gestionar servicios a través de internet. Hoy en día las tecnologías en la nube se utilizan prácticamente en todas las empresas de TI modernas.

En palabras simples:

Es el funcionamiento de servidores y servicios a través de internet sin necesidad de tener servidores físicos propios.

Microsoft Azure

Descripción:

Azure es una plataforma en la nube de Microsoft para ejecutar servidores, aplicaciones y diversos servicios de TI. Azure se utiliza para infraestructura cloud, almacenamiento de datos, máquinas virtuales y sistemas corporativos. La plataforma se aplica activamente en entornos empresariales y grandes compañías.

En palabras simples:

Es la nube de Microsoft para ejecutar servidores y servicios a través de internet.

Amazon AWS Basics

Descripción:

AWS (Amazon Web Services) es una de las plataformas en la nube más populares del mundo. AWS proporciona servidores, bases de datos, redes y numerosos servicios cloud para empresas y desarrolladores. Muchos sitios web y aplicaciones modernos funcionan precisamente sobre AWS.

En palabras simples:

Es el enorme sistema en la nube de Amazon para servidores y aplicaciones.

Virtual Machines

Descripción:

Virtual Machines son computadoras virtuales que funcionan dentro de un servidor físico. Cada máquina virtual tiene su propio sistema operativo y configuración. La virtualización permite ejecutar varios servidores en un solo dispositivo.

En palabras simples:

Son computadoras virtuales dentro de un servidor real.

Microsoft 365

Descripción:

Microsoft 365 es un conjunto de servicios y aplicaciones en la nube de Microsoft para el trabajo y los negocios. Incluye Outlook, Teams, OneDrive, Word, Excel y otras herramientas. Microsoft 365 es ampliamente utilizado por las empresas para el trabajo colaborativo y la gestión de usuarios.

En palabras simples:

Son los servicios en la nube de Microsoft para el trabajo, el correo y los documentos.

Microsoft Entra ID

Descripción:

Entra ID es un sistema de gestión de usuarios y acceso en la infraestructura en la nube de Microsoft. Anteriormente el servicio se llamaba Azure Active Directory. Entra ID se utiliza para la autorización, la seguridad y la gestión del acceso de los empleados a los servicios de la empresa.

En palabras simples:

Es el sistema de inicio de sesión, usuarios y seguridad en la nube de Microsoft.

☁️ Cloud Systems

Descripción:

Cloud Systems son infraestructuras en la nube modernas en las que funcionan servidores, bases de datos, aplicaciones y servicios de red. Los sistemas en la nube permiten escalar rápidamente los proyectos y gestionar la infraestructura a través de internet. Son la base de la mayoría de los servicios de TI modernos.

En palabras simples:

Son los servidores y servicios que funcionan en la nube a través de internet.
